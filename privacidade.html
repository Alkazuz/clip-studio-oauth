Política de privacidade do Clip Studio

Última atualização: 12 de novembro de 2026.

O que o aplicativo faz

O Clip Studio é uma ferramenta pessoal que envia vídeos para os canais do YouTube do próprio usuário, usando a YouTube Data API v3.

Quais dados são acessados

  • O nome e o identificador do canal do YouTube, para confirmar em qual canal o vídeo será publicado.
  • A permissão de enviar vídeos (título, descrição, tags, capa e agendamento) para esse canal.

Como os dados são usados e guardados

Os dados são usados só para publicar os vídeos que o próprio usuário escolheu. A chave de acesso fica guardada apenas no computador do usuário. Nenhum dado é enviado a servidores do aplicativo, vendido, compartilhado com terceiros ou usado para publicidade.

Como parar o acesso

Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
